# ostinato-forge

Product repositories by [eparenti](https://github.com/eparenti). Each one is built with AI coding agents under one rule: a deterministic core decides, models propose, and the result is accepted on evidence.

Public today:

| Repository | What it is | License |
|---|---|---|
| [field-manual](https://github.com/ostinato-forge/field-manual) | Practical engineering with AI coding agents: the practices, the method, the agent contract, and the templates | CC BY 4.0 |
| [divisi](https://github.com/ostinato-forge/divisi) | Separate rootless Podman contexts for AI coding agents, one identity per context | Apache-2.0 |
| [verdx](https://github.com/ostinato-forge/verdx) | Generic verification-engine framework with typed obligations and replayable evidence | Apache-2.0 |
| [workings](https://github.com/ostinato-forge/workings) | A training platform for any subject: playable lessons that show how a system actually works. First course: AI language models | Apache-2.0 |
| [agent-collab](https://github.com/ostinato-forge/agent-collab) | Two-agent collaboration protocol: one architects, one builds, branches and pull requests are the contract | Apache-2.0 |
| [jit-cognition](https://github.com/ostinato-forge/jit-cognition) | A research program for verifier-governed agents | CC BY 4.0 |
| [continual-learning-lab](https://github.com/ostinato-forge/continual-learning-lab) | Preregistered experiments on learning new rules without forgetting old ones | Apache-2.0 |
| [ambara](https://github.com/ostinato-forge/ambara) | Cross-session memory for AI coding agents: a knowledge repo with review branches and value receipts | Apache-2.0 |

The rest of the org is private work in progress. The map of everything is on the [profile page](https://github.com/eparenti).
